📊 Power BI Practice Dataset — Pivot & Unpivot Tutorial

This dataset is designed for hands-on practice with Pivot and Unpivot transformations in Power BI (Power Query).

It is used in the tutorial video from my YouTube channel Data Gyan by Rachit where I demonstrate how to reshape raw data into an analytics-friendly format.


📁 Dataset Overview

The dataset contains simulated business data structured like real corporate reporting formats.

Columns included:

Metric (Revenue / Expenses / Profit)

City (Delhi, Mumbai, Hyderabad)

Company (Reliance, TCS, Infosys, Wipro, HCL, Flipkart, Paytm, Zomato)

Monthly values (Jan 2026 → Jul 2026)

🎯 Purpose of This Dataset

This file helps you practice:

Unpivoting columns into rows

Pivoting rows into columns

Preparing data for analysis

Structuring data for dashboards

Understanding analytics-friendly formats

🧠 Why This Matters

In real-world analytics, raw data rarely comes in clean format.
Data professionals spend a large portion of their time transforming and reshaping datasets before analysis.

Mastering Pivot & Unpivot is a fundamental Power BI skill every analyst should know.
